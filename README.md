# RavMP Landing Page

The official website for **RavMP**, the GTA San Andreas multiplayer launcher for Windows and Android.

🌐 **Live site:** https://ravmp.site/

## What's here?

This repository contains the source code for the RavMP landing page, including its download links, project information, and website styling.

## Built with

- HTML
- CSS
- JavaScript

## Development

The site is static, so you can run it locally with any simple HTTP server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
